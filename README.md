# ResellHub — 배포

이 저장소는 [ResellHub](https://github.com/mask0331-coder/resellhub) 앱의
**빌드된 설치 파일과 자동 업데이트 정보만** 올려두는 공개 저장소입니다. 소스코드는
비공개 저장소에 그대로 있고, 여기엔 없습니다.

## 다운로드 및 설치

1. [Releases](https://github.com/mask0331-coder/resellhub-releases/releases)에서
   최신 버전의 `ResellHub_x.x.x_x64-setup.exe` 파일을 받습니다.
2. 다운로드한 파일을 실행합니다.
   - **"Windows에서 PC를 보호했습니다"라는 경고가 뜰 수 있습니다** — 아직 유료
     코드사이닝 인증서를 발급받지 않아 나타나는 정상적인 경고입니다(악성코드가 아닙니다).
     "추가 정보"를 클릭한 뒤 "실행" 버튼을 눌러 진행해주세요.
3. 설치 마법사를 따라 진행하면 설치가 끝나고 앱이 자동으로 실행됩니다.

앱을 실행한 뒤에는 "계정 로그인" 화면에서 앱 계정으로 먼저 회원가입/로그인해야 합니다
(초대 코드가 필요합니다). 그다음 KREAM/POIZON/MUSINSA 계정을 각각 로그인하면 됩니다.

## 필요 사항

- **Windows 10/11 (64비트)** — 지금은 Windows 빌드만 배포합니다.
- **Google Chrome이 설치돼 있어야 합니다.** KREAM 등 사이트 자동화가 실제로 설치된
  Chrome을 이용합니다 — [chrome.google.com](https://www.google.com/chrome/)에서
  먼저 설치해주세요. 없이 실행하면 앱이 안내 메시지로 알려줍니다.

## 업데이트

- **앱을 켤 때**: 새 버전이 있으면 묻지 않고 바로 설치한 뒤 앱을 다시 시작합니다.
- **앱을 켜둔 동안**: 30분마다 조용히 확인만 하고, 새 버전이 있으면 타이틀바에 "새 버전
  vX.Y.Z" 배지로만 알려줍니다 — 작업 중 자동으로 설치·재시작되지 않습니다. 배지를 누르면
  그때 설치할지 물어봅니다.
- **직접 확인**: 타이틀바 오른쪽의 "업데이트 확인" 버튼으로 언제든 수동으로도 확인할 수
  있습니다.
